Yes, there are several websites and APIs that provide video sources or direct streaming links for movies and web series. However, it is crucial to distinguish between legal/public domain sources and pirated/informal sources, as this affects how you scrape them and where you can host your app.
Here’s a breakdown of options categorized by type:
1. Legal & Public Domain Sources (Safe for Scraping)
These sites are legal to use and often have open APIs or accessible HTML structures.

Internet Archive (archive.org)
Content: Over 50,000 free movies and web series (public domain classics like Night of the Living Dead, His Girl Friday, etc.).
Video Source: Direct MP4/MKV links available via their API or by inspecting video players.
Scraping Ease: High. They have a well-documented API and consistent HTML structure.
Best For: Classic movies, indie films, public domain content.

YouTube (Official Channels)
Content: Many studios and creators upload full movies legally (e.g., Warner Bros. Classics, Sony Pictures).
Video Source: YouTube embed or direct stream URLs.
Scraping Ease: Medium. You can use the YouTube Data API to get metadata and video IDs, then generate embed links.

Tubi / Crackle / Pluto TV
Content: Free ad-supported streaming services (FAST).
Video Source: These are harder to scrape directly because they use dynamic HLS/DASH streams with token-based authentication. However, you can sometimes extract direct .m3u8 links using browser developer tools or third-party parsers.
Scraping Ease: Low to Medium. Requires handling session tokens and referrer checks.

Open Movie Database (OMDb) + Video Links
While OMDb itself doesn’t host videos, some community-driven sites aggregate links from legal sources. You can combine TMDB metadata with these link sources.

2. Popular "Link Aggregator" Sites (Commonly Scraped)
These sites don’t host content themselves but provide direct video URLs or embeds from various hosts. Note: Many are informal and may have copyright issues depending on your jurisdiction.

Putlocker-style sites (e.g., Putlocker, 123movies clones)
Content: Huge libraries of recent movies and series.
Video Source: Usually embeds from third-party hosts like StreamTape, DoodStream, Fembed, etc.
Scraping Strategy: You scrape the page for an <iframe> source or a direct .m3u8/.mp4 URL. These sites change frequently, so your scraper needs to be robust.
Pros: Tons of content, recent releases.
Cons: Ads, pop-ups, links can break often, copyright risks.

Filmix / Zimmo / KinoPoisk (Russian/Global)
Content: Large libraries with high-quality video links.
Video Source: Often provide direct MP4 or HLS streams.
Scraping Ease: Medium. Some have APIs, others require HTML parsing.

AllMoviesHub / Movierulz clones
Content: Very popular for web series and movies.
Video Source: Direct links or embeds.
Cons: Frequently changing domains, lots of ads.

3. How to Scrape Video Links

Identify the Video Element: Use browser DevTools (F12) to find the <video> tag or the source element that contains the .mp4, .m3u8, or .webm URL.

Handle Dynamic Content: Many sites use JavaScript to load video URLs. You may need to use:
Selenium/Playwright for full page rendering.
Requests + BeautifulSoup if the URL is in the HTML source.
API Reverse-Engineering: Some sites have hidden APIs that return JSON with video links. Check Network tab in DevTools.

Extract HLS Streams: For .m3u8 files, you can either:
Store the .m3u8 URL and let the user’s player (like Video.js) handle it.
Use a tool like ffmpeg to convert it to a direct MP4 if needed.

4. Recommended Approach for Your App

Use TMDB for Metadata: Continue using TMDB API for titles, posters, descriptions, etc. (It’s free and reliable).

Choose a Video Source Strategy:
Option A (Legal/Safe): Scrape Internet Archive for public domain movies. Use YouTube API for legal full-length films.
Option B (Popular/Informal): Pick 2–3 popular link aggregator sites (e.g., Filmix, Putlocker clones). Write a scraper to extract video URLs based on the TMDB ID or title match.
Option C (API-Based): Use services like MovieData or VideoSift which provide APIs that return direct video links for movies/series.

5. Important Considerations

Copyright: If you’re scraping from informal sites, ensure you’re not violating their Terms of Service or copyright laws in your region.

Rate Limiting: Don’t hammer the target website. Add delays between requests to avoid getting IP-banned.

Link Expiry: Video links on aggregator sites often expire after a few hours/days. You’ll need a system to refresh links periodically.

User Experience: Consider using an embedded player (like Video.js) that supports HLS streams for smooth playback.
